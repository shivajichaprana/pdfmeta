# Code of Conduct

## Our pledge

We want pdfmeta to be a welcoming, harassment-free project for everyone,
regardless of background or experience level.

## Our standards

Examples of behavior that helps:

- Being respectful and considerate in issues, pull requests, and reviews.
- Giving and accepting constructive feedback gracefully.
- Focusing on what is best for the project and its users.

Unacceptable behavior includes harassment, insults, personal or political
attacks, and publishing others' private information.

## Enforcement

Instances of unacceptable behavior may be reported to the maintainer via a
GitHub issue or the security contact in [SECURITY.md](SECURITY.md). The
maintainer may remove comments, commits, or contributions that violate this
Code of Conduct, and may ban repeat offenders.

This Code of Conduct is adapted from the
[Contributor Covenant](https://www.contributor-covenant.org), version 2.1.
